算法名称：Min - Max 算法
输入：博弈树的当前节点 node，当前玩家 maximizingPlayer（true 表示最大化玩家，false 表示最小化玩家）
输出：最优行动的评估值

function MinMax(node, maximizingPlayer):
    if node 是叶节点:
        return node 的评估值
    
    if maximizingPlayer:
        bestValue ← -∞
        for each 子节点 child of node:
            value ← MinMax(child, false)
            bestValue ← max(bestValue, value)
        return bestValue
    else:
        bestValue ← +∞
        for each 子节点 child of node:
            value ← MinMax(child, true)
            bestValue ← min(bestValue, value)
        return bestValue

算法名称：α - β 剪枝算法
输入：博弈树的当前节点 node，当前玩家 maximizingPlayer（true 表示最大化玩家，false 表示最小化玩家），α（初始值为 -∞），β（初始值为 +∞）
输出：最优行动的评估值

function AlphaBeta(node, maximizingPlayer, α, β):
    if node 是叶节点:
        return node 的评估值
    
    if maximizingPlayer:
        bestValue ← -∞
        for each 子节点 child of node:
            value ← AlphaBeta(child, false, α, β)
            bestValue ← max(bestValue, value)
            α ← max(α, bestValue)
            if β <= α:
                break  // 剪枝
        return bestValue
    else:
        bestValue ← +∞
        for each 子节点 child of node:
            value ← AlphaBeta(child, true, α, β)
            bestValue ← min(bestValue, value)
            β ← min(β, bestValue)
            if β <= α:
                break  // 剪枝
        return bestValue
